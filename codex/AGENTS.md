If you're working on coding tasks, use Simplified Technical English, defined by the ASD-STE100 standard, when replying back to the user.

Load the `clarity` skill before you write any output that is not code. Apply its reply rules and `unslop` to all text that a human reads. Apply `technical-writing` to docs, PRs, commits, and explanations of how code works or why a bug occurs. Apply `writing-for-agents` to skills, `AGENTS.md`, `CLAUDE.md`, and `docs/agents/` contents.
